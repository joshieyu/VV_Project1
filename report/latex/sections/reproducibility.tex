\section{Reproducibility, demo, and contributions}
\label{sec:repro}

Every result in this report comes from a seeded command in the team repo,
\url{https://github.com/joshieyu/VV_Project1}. The clean directed suite is
\begin{verbatim}
make -C tb/fifo SIM=icarus RANDOM_SEED=4701
\end{verbatim}
It passes on the course machine (Eustis, Icarus 12.0, cocotb 1.9.2) with the
same simulated time as locally (\texttt{evidence/driver-monitor/eustis-clean.log}).

The final CRV regression and released mutant campaign ran on the course VM:
\begin{verbatim}
python crv/run_regression.py --sim icarus \
  --seeds 4701,4702,4703 --short-cycles 128 \
  --cycles 2048 --mutate
\end{verbatim}
Results: random-only X1 36/36 per seed, exact seed-4701 replay, and 8/8
released mutants (\path{evidence/crv/}).
